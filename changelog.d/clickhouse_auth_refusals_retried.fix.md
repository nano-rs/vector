The `clickhouse` sink retries authentication and access refusals instead of dropping the batch: HTTP 401 and 403, and any error whose body carries ClickHouse code 192 (UNKNOWN_USER), 193 (WRONG_PASSWORD), 194 (REQUIRED_PASSWORD), 195 (IP_ADDRESS_NOT_ALLOWED), 497 (ACCESS_DENIED) or 516 (AUTHENTICATION_FAILED). Upstream's default strategy treated them as permanent, so a wrong password, a dropped user, a grant regression or user `networks` that no longer admit Vector's address discarded every batch the sources had already acknowledged. The batch now stays in the sink's buffer and is retried with the usual backoff until access is restored; with `buffer.when_full = "block"` a lasting refusal pushes back on the sources. Data errors (codes 117 and 53) are still not retried (NAN-5390).
